## 1D Dynamic Programming

This folder contains **1D DP problems** solved using:
- recursion
- memoization
- bottom-up tabulation

---

### 🧠 Problems Covered

1. Climbing Stairs (LeetCode 70)
2. Min Cost Climbing Stairs (LeetCode 746)
3. House Robber (LeetCode 198)
4. House Robber II (LeetCode 213)
5. Fibonacci Number (Leetcode 509)
---

### 📌 Patterns Identified

- Fibonacci-style DP
- Take / Not Take
- Circular DP (range splitting)
- Dependency-based tabulation

---

### 📝 Note

Emphasis is on **understanding DP flow**, not just passing test cases.
