# Binary Search Tree Problems

This folder contains Binary Search Tree (BST) problems solved in **C++** for placement preparation.

## Concepts Covered

* BST Search & Insert
* BST Validation
* Lowest Common Ancestor (LCA)
* Kth Smallest Element
* BST Iterator
* Delete Node in BST
* Balanced BST
* Largest BST
* Range Sum in BST
* Predecessor & Successor

## Platforms

Problems are mainly solved from **LeetCode** and interview-focused DSA practice.

## Goal

To strengthen tree problem-solving skills for coding interviews and placements.
