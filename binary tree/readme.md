# Binary Tree Problems 🌳

This folder contains **Binary Tree DSA problems** solved in **C++** for placement preparation.

## Topics Covered

### EASY
- Tree Traversal
- Level Order Traversal
- Height / Depth of Tree
- Symmetric Tree
- Path Sum
- Tree Views
- Lowest Common Ancestor (LCA)

### MEDIUM
- Tree Construction
- Tree Flattening
- Maximum Path Sum
- Infection Time
- Advanced Traversals

## Platforms

Problems are mainly solved from **LeetCode** and interview-focused DSA practice.

## Goal

To strengthen Binary Tree concepts for coding interviews and placements.
