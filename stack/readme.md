# Stack Problems

This folder contains stack-based Data Structures and Algorithms (DSA) problems solved in **C++** for placement preparation.

## Concepts Covered

* Basic Stack Operations
* Monotonic Stack
* Next Greater Element
* Parentheses Problems
* Expression Evaluation
* Histogram Problems

## Platforms

Problems are mainly solved from **LeetCode** and interview-focused DSA practice.

## Goal

To strengthen problem-solving skills for coding interviews and placements.
